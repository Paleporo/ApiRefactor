# Paginazione

- [PAGINATION-001] Le operation GET che restituiscono collezioni dovrebbero supportare la paginazione
  tramite i query parameter `limit` e `cursorId`.
Le operation GET che restituiscono collezioni dovrebbero supportare la paginazione tramite i query parameter `limit` e `cursorId`. Regola di giudizio: richiede di valutare quali GET restituiscono collezioni; non riguarda gli status code.
